# Parqueo Tu favorito
## _Nombre del Proyecto_ 🚀

### ✅ Descripción del proyecto
Aplicacion de JS combinado con HTML5 Y CSS3 para llevar un control de los datos de un parqueo en el cual se debe poder agregar el tipo de vehiculo, eliminarlo, o editarlo mas no se podra repetir, al igual que al registrar los vehiculos, se tomara en cuanta la tarifa por hora, no podra repetirse tanto la placa como el slot asignado, y al cobrar la tarifa el slot sera vaciado junto con su registro. Solo el ususario administrador podra tener acceso al mismo.
